\# Auto-École SaaS – Backend



\## Prerequisites

\- Java 17

\- Maven

\- Docker



\## Local setup



1\. Copy environment file:

&nbsp;  cp .env.example .env



2\. Start PostgreSQL:

&nbsp;  docker-compose up -d



3\. Run backend:

&nbsp;  mvn spring-boot:run



Backend URL:

http://localhost:8080
